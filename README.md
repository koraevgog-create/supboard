# SUPBOARD — бизнес-лаборатория

Внутренний интерактивный штаб проекта продажи и аренды сапбордов в Набережных Челнах.

## Старт
Откройте `index.html` в браузере или опубликуйте сайт через GitHub Pages.

### GitHub Pages
1. Откройте **Settings → Pages** в этом репозитории.
2. В **Build and deployment** выберите **Deploy from a branch**.
3. Выберите **main** и **/(root)**, затем **Save**.
4. После успешной публикации ожидаемый URL: https://koraevgog-create.github.io/supboard/

URL станет рабочим только после включения Pages и завершения публикации. Состояние Pages необходимо проверить в настройках репозитория.

## Состав
- Пульт и подтвержденные показатели спроса 2026
- Модель: закупка, продажи, аренда, сезонные расходы, упрощенные налоги, износ, остаточная стоимость
- Ассортимент и точка дозаказа
- Тестовый журнал аренды с CSV
- Продажная воронка, партнёрство, риски
- Дорожная карта и чек-лист

## Важно
Это MVP на статическом HTML/CSS/JS, без backend. Данные формы и настроек сохраняются в LocalStorage только в текущем браузере, не синхронизируются между сотрудниками и могут исчезнуть после очистки данных браузера. Не храните в журнале персональные данные клиентов. Экспортируйте CSV регулярно.

Начальные расходы за исключением закупки и цен — сценарные предположения, которые нужно подтвердить коммерческими предложениями и реальными документами. Финансовая модель не заменяет бухгалтерский и налоговый учёт.

## Следующая очередь разработки
1. Утвержденные модели, артикулы, индивидуальная себестоимость, реальный остаток.
2. Облачная база (например, Supabase) и авторизация партнёров.
3. Календарь бронирований с проверкой конфликтов.
4. CRM заявок, контрагентов и заказов.
5. Складские перемещения, ремонты и отчёт о денежных потоках.
